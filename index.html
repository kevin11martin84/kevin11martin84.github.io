Personal Google utilities

This project contains personal desktop utilities used by the account owner. Google’s consent screen displays YouTube Playlist Migration Reader, the name of the existing Google authorization project.

Kevin Memory Drive Sync

Kevin Memory Drive Sync uses the open-source rclone application to copy selected local pictures, PDFs, audio and design files to the account owner’s Google Drive. Its permission is drive.file, which covers files created with this connection or specifically authorized for it.

The sync retains older copies of replaced or removed Drive files in a separate backup folder. New local changes upload when the owner’s computer is awake and the scheduled sync runs. Uploaded copies remain in Google Drive while the computer is asleep.

Existing YouTube utility

An older personal YouTube playlist reader shares this Google authorization project. The Drive sync has its own desktop client and requests only its stated Drive permission.

Read the privacy notice and use notice for the Drive sync. Questions can be directed to the maintainer’s GitHub profile.
