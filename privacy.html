Privacy notice

This notice describes Kevin Memory Drive Sync, a personal desktop backup utility. Google’s consent screen may show the shared project name YouTube Playlist Migration Reader.

Google Drive data

The utility sends selected local files and their names, folder locations, sizes and modification times to the account owner’s Google Drive. It reads metadata and checksums for files available to its connection to verify the backup and generate a file inventory. Its Google permission is drive.file.

Storage and access

File copies and retained older versions are stored in the account owner’s Google Drive. A path-and-size inventory is stored in the owner’s private shared-memory repository. OAuth credentials are stored on the owner’s computer and used to authenticate with Google.

The backup utility does not sell account data, use it for advertising, or make files public. Separately connected AI tools may read Drive files under the permissions the owner grants those tools. Those connections are controlled separately from this utility.

Retention and control

The owner controls stored copies in Google Drive and the private inventory. Replaced or removed files are retained in a backup area without an automatic expiration. Revoking the utility in Google Account connections stops its authorized access. Revocation does not remove copies already stored in the owner’s Drive.

This website

These static pages contain no forms, analytics code or file-upload functions. GitHub Pages hosts them and processes ordinary web requests under the GitHub privacy statement. Private files and credentials are not part of this website.
